## Agent skills

### Issue tracker

Issues and specifications for this repo are tracked in GitHub and managed using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage states are mapped to five canonical roles (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix). See `docs/agents/triage-labels.md`.

### Domain docs

The domain documentation follows a single-context layout. See `docs/agents/domain.md`.
