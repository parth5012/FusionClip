Prototype notes — decisions made

  • Placement: fullscreen overlay modal (chosen). Inline card + dedicated page kept as reference shells.
  • Trigger: on-demand from the asset's catalog card — hover the slider icon on a card that has an upscaled sibling to open the modal. No auto-open on task completion.
  • Interaction: drag the circular handle (or arrow keys) to reveal original vs. upscaled. Zoom magnifier ships in v1 — it tracks the divider while dragging or when hovering near it.
  • Data model: requires linking the source asset to its upscaled output (the task result already returns original_object — persist that relation so the UI can pair them).
